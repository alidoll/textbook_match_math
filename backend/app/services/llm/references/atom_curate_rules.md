# 旧库教材原子 AI 整理规则（湘科版小学科学）

供 `atom_curate_suggest.py` 与教研复核参考。视觉 Agent 整理 OCR 粗原子时使用。

## 分工（重要）

| 步骤 | 职责 |
|------|------|
| **OCR 本页** | PDF 字层 + RapidOCR → 粗原子（文字块、插图块）。只做基础同行合并、拼音+汉字配对，**不在此层裁框、删双层、合并示意照** |
| **AI 整理本页** | **第一步识别全部大/小标题条** → 规则兜底 + 视觉 LLM → merge/delete，达到教研标杆粒度 |

> 标题条视觉特征全集见同目录 **[title_bar_visual_guide.md](./title_bar_visual_guide.md)**（橙/绿/teal 大标题；浅蓝/cyan/黄渐变小标题；icon+汉字 merge 范例）。

## 标题条铁律（AI 整理每页必执行）

1. 找出本页全部 `lesson_title_bar`（页顶课节条）与 `subtitle_bar`（活动小标题条）
2. 每条标题：条内 OCR 碎段（序号圈/小人 icon/拼音/汉字/条底）→ **同一 bar_id，merge 为 1 原子**
3. **禁止**标题与插图、气泡、说明句、记录块、其他标题 **跨组 merge**
4. **禁止** delete 标题条任何组件

## 原子类型（教研口径）

| 类型 | 特征 | 处理 |
|------|------|------|
| 对话原子 | 气泡内台词，常含「…」「。」；如「我带来了铜钱草」 | **单独保留**，不并入插图 |
| 活动条原子 | 左侧小人/图标 + 浅蓝条内「建植物角」及拼音 | **合并为一原子** |
| 课节标题条 | 顶部「1 推拉游戏」「1 植物角」+ 拼音 | **单独原子**，一行；不与活动条、插图合并 |
| 场景插图原子 | 人物+道具+环境；角 inset 小圆图属同幅 | **整图一原子** |
| 场景标牌 | 墙上/架上「植物角」等 | **delete 或并入主插图** |
| 主图+右侧卡通 | 课堂大图 + 右侧指南车/小卡通 | **合并为一插图原子** |
| 主图+角 inset | 主场景 + 右上角 inset（如推手特写） | **合并为一插图原子** |
| 底部并列小图 | 页底左右并列示意（拉/推各一张） | **合并为一插图原子** |
| 引导问句 | 拼音 + 「你还在什么情况下…？」等 | **拼音+汉字合并一行** |
| 课节引导问句 | 标题下「物体是怎么变形的？」 | **单独一行**，不与标题/活动条合并 |
| 活动说明句 | 「挤压和拉伸橡皮泥，观察形状的变化。」 | **单独一行**，拼音+汉字合并 |
| 说一说引导 | 「说一说你是怎样用力的。」 | **单独一行**，拼音+汉字合并 |
| 结论/总结句 | 「力可以改变橡皮泥的形状。」 | **单独一行**，拼音+汉字合并 |
| 步骤示意照 | 2×2 操作步骤图、多张作品展示图 | **每张单独一块**，不合并 |
| 页底对比小图 | 仅页底左右对比（拉/推各一张） | **两张 merge 为一块** |
| 页码 | 页脚/页角单独数字「2」「4」「8」 | **删除**，不框不绑 |

## 标杆页：推拉游戏（人工整理标准）

教研人工框可作为粒度参照（一课内页，非跨页）：

| 顺序 | 原子 | 内容 | 要点 |
|------|------|------|------|
| 1 | 课节标题 | `1` + `推拉游戏`（拼音+汉字） | 紧贴顶部蓝条，**一行一块** |
| 2 | 活动条 | 小人图标 + `「推手」与「拔河」游戏` | **一行一块**，不向上蔓延 |
| 3 | 场景插图 | 推手主图 + 角 inset + 老师 | **一块**包住整幅场景 |
| 4 | 对话 | `游戏中后移动脚者为胜` | **独立原子**，在气泡内，**不 merge 进插图** |
| 5 | 场景插图 | 三小孩玩小棍 + inset | 同上 |
| 6 | 对话 | `游戏中后松开小棍或后移动脚者为胜` | 独立对话原子 |
| 7 | 引导问句 | 拼音 + `你还在什么情况下用到了推和拉？` | **一行合并** |
| 8 | 并列小图 | 拉弹簧女孩 + 推箱子男孩 | **两张 merge 为一块** |
| — | 页码 | 左下角 `2` | **删除**，不与任何块绑定 |

### 标杆页原则（全册通用）

1. **一行一块** — 标题条、活动条各占一行，竖向不跨板块。
2. **对话永远单独** — 即使在插图区域内，只框气泡文字。
3. **主图要完整** — inset、人物、环境在同一插图原子里。
4. **同类小图可合并** — 页底左右并列示意合成一块。
5. **页码独立** — 不和小人、插图、文字绑在一起。
6. **不要里外双层** — 每个内容元素只保留一层有效原子框（删 OCR 外包大框）。

### 与推拉游戏页的差异

| 版面 | 推拉游戏 | 力与形变 |
|------|----------|----------|
| 页底小图 | 左右对比两张 → **合并一块** | 2×2 步骤图 → **各留一块** |
| 标题下问句 | 无 | `物体是怎么变形的？` **单独原子** |
| 活动条下 | 直接插图/对话 | 另有 **活动说明句** 单独原子 |

## 常见问题与对策

### 1. 插图内标牌被拆成文字原子

墙上/架上的「植物角」是场景的一部分，不是对话。将标牌文字原子与主插图 **merge**，或 **delete** 标牌、只留大图。

### 2. 活动条方框过大，蔓延到上方标题或下方说明

OCR 常产出 **里外双层**：外包大框（拼音+条名+说明句）+ 内贴条名小框。

对策：
1. **delete** 蔓延大框（`drop_outer_text_with_inner_duplicate` / `detect_activity_bar_span_deletes`）
2. 活动条与说明句 **拆开**（`split_activity_bar_and_instruction_atoms`）
3. 活动条 **裁高** 为一行（`clamp_activity_bar_band_height`）
4. 再 **merge** 小人图标 + 拼音 + 条内汉字

### 3. 对话未单独识别

带「…」「。」的台词必须在气泡内 **单独原子**；若被大图框住，**delete** 过大图框或拆出对话。

### 4. 主图与 inset / 右侧小人不合并

主场景与角 inset、右侧小卡通 **merge** 为一 `image` 原子。

### 5. 页底并列小图被拆成两块

**仅**页底左右对比示意（拉弹簧 + 推箱子，**恰好两张**）→ merge 为一插图原子。

**禁止**合并：2×2 步骤示意照、多张作品展示图（力与形变页）——每张保持独立原子。

### 6. 课节引导问句与活动说明被合并

标题下「物体是怎么变形的？」→ 单独原子，不与课节标题、活动条 merge。

活动条下的说明句「挤压和拉伸…观察…」→ 单独原子，拼音+汉字一行 merge。

### 7. 页码

`y > 0.72` 且纯 1–3 位数字 → **delete_codes**；勿与页底横条、小人合并。

### 8. 问题情境大框（整框 1 原子）

**长什么样：** 课首/页内**单一圆角矩形大框**（常见浅黄底 + 黄边），框内可有：左上角装饰图标（信箱等）、多行引文/说明 text、右侧带框插图。

**怎么处理：** 框内**全部** OCR 原子 → role=`problem_context_block`，同一 `context_id`，**merge 为 1 个原子**；`section_module` 可填 `问题情境`。

**禁止：** 只 merge 文字漏图标/插图；与框外活动条/气泡 merge。

### 9. 记录过程 / 计划书（记事本块整框 1 原子）

**长什么样：** 独立浅蓝**记事本/计划表**视觉块（顶装订孔/波浪边），含采访录（标题+时间+对象+问/答）或计划书（标题+编号列表）。

**怎么处理：** 每一块内**全部** OCR 原子 → role=`process_record_block`，同一 `record_id`，**merge 为 1 个原子**；`section_module` 可填 `记录过程` / `计划书`。

**禁止：** 漏并标题/日期/问答或编号行；同页两块记事本跨块 merge；块内「问/答」误标 dialogue_bubble。

## 合并边界（禁止）

- 课节标题条 ↔ 活动条 ↔ 课节引导问句（三者各一块，纵距大）
- 活动条 ↔ 活动说明句（条名与说明句分开）
- 步骤示意照 / 作品展示照 ↔ 彼此（多张各留一块）
- 对话气泡 ↔ 场景插图
- 引导问句 ↔ 上方插图或活动条
- 跨页、占位条（-GAP-）

## 结构化备注（metadata_json.curate）

AI 整理除 merge/delete 外，为每个原子写入 `metadata_json.curate`，供后续对话配对、跨页筛图、板块汇总：

| 字段 | 用途 | 示例 |
|------|------|------|
| `dialogue_group_id` | 同一轮对话左右气泡关联（**不 merge**） | `dlg_1` |
| `dialogue_side` | 左/右气泡 | `left` / `right` |
| `group_slot` | 同组子序号 | `1`（左）、`2`（右） |
| `image_category` | 跨页同类插图标签 | `形变实物图`、`制陶工序图` |
| `section_parent` | 大栏目 | `科学探究` |
| `section_module` | 子模块 | `指南信箱`、`捏陶泥实操`、`问题情境` |
| `context_id` | 问题情境大框内元素（整框 merge） | `ctx_1` |
| `record_id` | 记录过程/计划书记事本块（整块 merge） | `rec_interview`、`rec_plan` |

**原则：**
- 同一气泡内 OCR 碎段 → 同 `bubble_id`，**merge 为 1 原子**
- 左右两个独立气泡 → **不同 `bubble_id`**，共用 `dialogue_group_id`，保留独立框
- 插图按视觉语义打 `image_category`，全课同类用同一标签词
- 大栏目下子模块内所有原子标注 `section_parent` + `section_module`
- 问题情境封闭大框内所有原子 → 同 `context_id`，**merge 为 1 原子**
- 记录过程/计划书记事本块内所有原子 → 同 `record_id`，**merge 为 1 原子**
