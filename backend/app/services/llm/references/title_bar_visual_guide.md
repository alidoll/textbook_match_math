# 标题条视觉识别指南（AI 整理大模型专用）

全册教材页在 **AI 整理** 时，第一步必须：**找出本页全部大标题与小标题 → 各自 merge 为 1 个原子 → 禁止与任何其他原子 merge 或 delete**。

本文档汇总湘科版（及同类 K12 教材）典型标题条外观，供 `atom_curate_suggest.py` 视觉 Agent 与教研复核。

---

## 铁律（每页必执行）

| 步骤 | 要求 |
|------|------|
| 1 识别 | 扫描整页，列出所有 `lesson_title_bar` 与 `subtitle_bar` |
| 2 标注 | 每条标题分配唯一 `bar_id`；条内每个 OCR 碎框（序号圈 image、小人 icon、拼音、汉字、条底 image）同 role、同 bar_id |
| 3 合并 | 同一 bar_id → **恰好 1 组 merge**，merge 后 = **1 个原子** |
| 4 隔离 | 标题 role 的原子 **禁止** 出现在含非标题原子的 merge 组中 |
| 5 保护 | 标题条组件 **禁止** 进入 delete_codes |

## 大标题 `lesson_title_bar`（课节标题）

### 版面位置
- **页顶**第一条彩色横条（y 通常 < 页高 14%）
- 下方才是插图、引导句、小标题、正文

### 视觉特征（满足多项即可认定）

| 特征 | 说明 | 全册实例 |
|------|------|----------|
| 宽幅色带 | 横向整页或近整页宽；**上圆角、下直边** 或全圆角胶囊 | 橙/黄渐变、青绿、 teal 绿 |
| 序号圈 | 左侧 **白底圆** 或 **白字圆底** 内阿拉伯数字 `1` `2` `3` `4`… | 「① 蚕宝宝出生了」「2 蚕宝宝在长大」 |
| 课题汉字 | 序号右侧 **大号白色或深色课题名**（4～12 字） | 「互相依存的动植物」「人类对生物的影响」「认识岩石」 |
| 可选拼音 | 汉字上方/同行小号拼音 | 「植物角」等 |
| 条内底图 | 序号圈、色块底可能被 OCR 为 **image** | 须与汉字同 bar_id |

### 色带颜色（全册变体，均属大标题）
- **橙→黄渐变**（最常见）：如「3 互相依存的动植物」「4 人类对生物的影响」
- **青绿 / teal 实色**：如「2 蚕宝宝在长大」「① 蚕宝宝出生了」
- **绿色实色**：如「1 认识岩石」

### OCR 碎段 → 1 原子
```
序号圈(image) + 拼音(text) + 课题汉字(text/title) + 条底(image)
→ 同一 bar_id=bar_lesson，1 组 merge
```

### 严禁
- 与下方 **场景插图、邮箱图、引导句** merge
- 与 **小标题条** merge（即使竖向相邻）
- 把序号圈或条底 image **delete** 或单独留框

## 小标题 `subtitle_bar`（活动条 / 板块小标题）

### 版面位置
- **页中**或**页底**（y 约 36%～82%）
- 在插图、说明句、气泡、记录块 **之间** 作为板块分界
- **不是**页顶课节大标题；**不是**气泡内台词

### 视觉特征

| 特征 | 说明 | 全册实例 |
|------|------|----------|
| 左侧 icon | **圆形**蓝底/彩底 + **白色小人**（跳跃/读书姿态） | 几乎所有活动条 |
| 胶囊条 | icon 右侧 **浅蓝/ cyan / 黄白渐变** 圆角长条 | 「了解怎样养蚕」 |
| 条内汉字 | 常 **楷体/宋体**，6～20 字；可含 **括号拼音** `(jì)` | 「调查白暨(jì)豚…」 |
| 背景线 | 条后常有 **浅色横线** 贯穿页面 | 仅装饰，icon+条内文字仍属同条 |
| 无气泡描边 | 文字在 **色带内**，无对话气泡尾巴 | 与 dialogue_bubble 区分 |

### 色带颜色（全册变体，均属小标题）
- **浅蓝 / cyan 胶囊**：「了解怎样养蚕」「蚕宝宝出生记」「蚕宝宝还喜欢吃什么」「观察蚕宝宝换'新衣'」
- **黄白渐变胶囊 + 橙边**：「认识鸟类与植物的关系」「调查银杏…」「人类对生物及其生存环境的影响」
- **浅绿胶囊**：「观察岩石」

### OCR 常见错误 → 正确整理
| OCR 现状 | 正确做法 |
|----------|----------|
| 小人 icon 1 框 + 条内汉字 1 框（**2 个原子**） | **必须 merge 为 1 原子** |
| icon + 汉字 + 括号拼音 各 1 框 | 同一 bar_id，全部 merge |
| 小标题与上方说明句在同一 merge 组 | **拆分**：说明句 instruction_line 单独；小标题 1 组 |
| 小标题与下方插图 merge | **禁止**；插图单独 illustration |

### 严禁
- 与 **上方说明句/引导句/正文** merge
- 与 **下方气泡、插图、采访录/计划书** merge
- **漏并**左侧小人 icon（只剩汉字框）
- 把条内汉字 **delete**（误以为重复或噪点）

## 大标题 vs 小标题 对照

| 维度 | 大标题 lesson_title_bar | 小标题 subtitle_bar |
|------|-------------------------|---------------------|
| 位置 | 页顶第一条 | 页中 / 页底 |
| 序号 | 课节号 `1`～`4` 在色带内 | 通常无课节号，有小人 icon |
| 色带 | 宽幅、饱和（橙/绿/teal） | 窄胶囊 + 浅色线 |
| 字号 | 最大 | 小于大标题 |
| bar_id | 每课 1 个（如 bar_lesson） | 每条条 1 个（bar_1, bar_2…） |
| 与相邻 | 下接插图/引导句，**不 merge** | 上下接正文/插图/气泡，**不 merge** |

---

## 与易混淆类型的区分

| 类型 | 区分要点 |
|------|----------|
| 对话气泡 dialogue_bubble | 有 **气泡描边+尾巴**；在气泡内，不在色带里 |
| 说明句 instruction_line | **无**色带、**无**小人 icon；普通正文排版 |
| 记事本标题 process_record_block | 在 **浅蓝记事本框内**（采访录/计划书），非活动条 |
| 插图内标牌 scene_label | 在 **场景图内部**，随 illustration merge |
| 页码 page_number | 页脚孤立数字，delete |
| 侧边栏 sidebar_unit_title | 页边 **竖排**「第X单元」，delete |

## 整理输出检查清单（每页自检）

- [ ] 本页有几个大标题？每个是否 **1 组 merge、1 个 bar_id**？
- [ ] 本页有几个小标题？每个是否 **icon+汉字+拼音 全部在同一 merge 组**？
- [ ] 是否存在 **标题 atom 与 non-title atom 同组**？若有，必须拆分
- [ ] delete_codes 是否 **不含** 任何 bar role 的 code？
- [ ] 每个 subtitle 的 **左侧 icon** 是否已 merge，未单独丢失？
